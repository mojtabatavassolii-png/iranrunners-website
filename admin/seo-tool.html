ابزار سئوی صفحه

تحلیل زنده‌ی سئوی هر صفحه از روی نسخه‌ی منتشرشده‌ی همون صفحه — مثل Yoast، ولی فقط نمایش و تحلیل. برای تغییر عنوان/توضیح متا/کلیدواژه، از Pages CMS استفاده کن (این ابزار چیزی رو ذخیره نمی‌کنه — دلیلش رو پایین توضیح دادم).

    چرا این ابزار خودش ذخیره نمی‌کنه

    سایت استاتیک روی GitHub Pagesه، بدون سرور. یک دکمه‌ی «ذخیره» که مستقیم از مرورگر با توکن گیت‌هاب کامیت بزنه یعنی اون توکن باید توی جاوااسکریپت همین صفحه باشه — و هر توکنی که توی مرورگر باشه، با یک نگاه به Network tab قابل‌دزدیدنه. به‌جاش، تغییرات از طریق Pages CMS (که توکن رو امن و سمت سرور خودش نگه می‌داره) ذخیره می‌شن؛ این ابزار فقط کمک می‌کنه بفهمی چی رو باید عوض کنی. بعد از ذخیره توی Pages CMS، معمولاً چند دقیقه طول می‌کشه تا GitHub Pages دوباره build کنه و تغییر روی سایت واقعی دیده بشه.
